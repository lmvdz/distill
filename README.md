# Distill

**Turn videos, articles, and research into useful notes.**

Distill helps you learn from videos, articles, and research. You choose a subject and
some sources. It turns the useful ideas into a collection you can come back to.

## What can it do?

- Pull out useful ideas, steps, and common mistakes.
- Keep the original sources beside the notes, so you can check the details.
- Make different collections from the same material.
- Help you find what you need in a finished collection.
- Update your collections as your sources or interests change.

It is especially useful for tutorials, practical how-to guides, and research.

## For example

> Collect ways to make stylized fire. Explain how each method works, when to use it,
> and where the explanation came from.

## Where things stand

This is an early working version. It needs setup before you can use it.
A simple connection to bookmark apps is planned.

Your personal sources and finished collections are kept out of this public project.
The AI service you use receives the material it works on.
